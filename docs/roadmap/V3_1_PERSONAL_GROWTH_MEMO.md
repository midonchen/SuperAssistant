# V3.1 个人成长方向规划（基于《知识体系.md》）

> 来源：用户个人《知识体系.md》（853 行个人价值观 / 学习方法 / 生活理念整理）
> 原则（贯穿全文）：未雨绸缪、富有耐心、严于律己、不偏不倚
> 状态：待评审（第五方向决策待确认）

## 一、文档分析结论

《知识体系.md》是用户的个人知识/价值观体系，覆盖五大主题：

1. 人生要事 —— 事业 / 健身 / 读书 / 兴趣 / 交友 / 习惯
2. 终身学习 —— 学习方法 / 读书 / 写作 / 践行 / 知识管理 / 个人成长 / 重要概念
3. 生活保障 —— 安全（财商/消费/赚钱/增值）/ 健康 / 投资
4. 为人处事 —— 交往 / 亲密关系 / 社会 / 独立 / 表现 / 工作
5. 关于理想 —— 成功 / 幸福 / 意义 / 希望

**核心发现**：现有四方向（生活/工作/关系/职业）已覆盖约 60% 内容，但缺失一个贯穿全文的
「个人成长 / 自我提升」维度 —— 习惯养成、健身、财务理财、知识管理（思维模型/价值观/
方法论）、读书清单、感悟日记、人生愿景。

## 三、方案建议（二选一，待确认）

- **方案 1（推荐）**：新增第五方向「成长」，底部导航 生活 / 工作 / 关系 / 职业 / 成长。
  理由：习惯、健身、财务、知识管理、思维模型、价值观、感悟、愿景是一个自成体系的
  「自我提升」域，与生活/工作/关系/职业天然区分，且是文档中占比最大、最独特的部分。
- **方案 2**：不新增方向，拆分归入现有四方向（健身/财务/习惯 → 生活，读书/知识 → 职业，
  感悟/价值观/愿景 → 生活）。优点是不动信息架构，缺点是把「成长」主题打散、感知弱。

## 四、里程碑（若方案 1）

- 成长 3.1：思维模型库 + 价值观/原则库（知识管理底座）
- 成长 3.2：感悟/日记 + 人生愿景
- 成长 3.3：习惯养成打卡 + 健身运动记录
- 成长 3.4：财务理财（资产配置 / 投资记录）
- 成长 3.5：移动端「成长」tab + Admin 概览 + demo 覆盖
