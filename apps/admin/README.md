# SuperAssistant Admin

Next.js skeleton for MVP core admin pages:

- `/dashboard`
- `/users`
- `/audit`

## Run

```bash
cd apps/admin
npm install
npm run dev
```

Set API base URL if backend is not on default local port:

```bash
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000/api/v1 npm run dev
```
